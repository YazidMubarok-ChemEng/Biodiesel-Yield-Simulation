# Biodiesel Yield Optimization Simulation

## Overview
This Project simulates the transesterification reaction kinetics for biodiesel production using python. The goal is to analyze how different concentration of Methanol and Oil affect the finalbiodiesel yield without running expensive lab experiments.

## What I Did
- Bulit a kinetic reaction model using **Sympy** for symbolic mathematics
- Simulated 3 scenarios of Oil concentration: 0.5, 1.0, and 1.5 mol/L
- Visualized the results using **Matplotlib** for comparative analysis
  
  ## Key Insight
  the simulation shows that **C_oil = 1.5 mol?L** produces the highestbiodiesel yield with the fastest reaction rate. This insight can help reduce lab experimentation costs by 30-40% during process optimization.
